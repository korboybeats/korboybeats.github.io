Changelog

New in 2.5.7

RootHide

  • Improved startup reliability when opening directly to Packages or Sources on RootHide.
  • Improved RootHide conversion support with all conversion modes available directly inside Sileo.
  • Fixed installed package source labels temporarily showing as Local while RootHide package data finishes loading.
  • Fixed Require Dynamic Patches converted packages not queuing correctly from package pages or Converted Packages.

Sources

  • Combined Sort Sources By, Clean Repos, and Treat Re-added Sources as New into one Sources options button.

Package Icons

  • Improved repo icon caching so package icons are less likely to fall back to category icons.
  • Fixed local deb icons when a package contains an icon file but does not declare an Icon field.

Localization

  • Added missing translations across supported languages.

Stability

  • Fixed installed packages staying visible in Packages after uninstalling.
  • Improved startup reliability and general stability.
